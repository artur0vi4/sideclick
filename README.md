# SideClick

**Free auto clicker for Windows — toggled by your mouse side buttons.**

One press of the side button — it clicks. One more press — it stops.
No holding, no hand cramps.

## ✨ Features

- **Side-button toggle** — start/stop clicking with mouse button X1/X2 (or **F8**)
- **Adjustable speed** — from 1 to 100 clicks per second
- **Choice of click button** — left, middle or right
- **Dark modern UI** — Tokyo Night theme, works on Windows 10 and 11
- **8 languages** — English, Русский, Español, Deutsch, Français, Português, Italiano, 中文
- **Lightweight** — a single portable `.exe`, no installation required

## 🚀 Quick start

1. Go to [**Releases**](https://github.com/artur0vi4/sideclick/releases)
2. Download `SideClick-v1.0.0.exe`
3. Run it — no installation needed

> **Note:** Windows SmartScreen may show a warning because the app is not code-signed.
> Click **More info → Run anyway**.

## 🛠️ Run from source

```bash
pip install -r requirements.txt
python sideclick.py
```

## 📦 Build your own exe

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --icon=sideclick.ico sideclick.py
```

## 🖱️ Usage

| Action | Control |
|--------|---------|
| Start / stop clicking | Mouse side button (X1/X2) or **F8** |
| Click speed | 1–100 CPS in the app |
| Click button | Left / Middle / Right |
| Language | Auto-detected, switchable in the app |
